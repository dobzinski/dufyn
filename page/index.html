Does DUFYN identify operating systems and types automatically?

Operating systems and types are assigned manually from shared catalogs. Discovery does not infer or overwrite these classifications. Assets without an assignment remain unclassified, and the OS ranking summarizes the operating systems you assign.

Are topology relationships discovered automatically?

Discovery populates the inventory. You maintain physical maps, logical hierarchies and Site Links. System diagrams connect Assets and Targets to document how an application or service is organized.

Can I connect my own monitoring tools?

Yes. The read-only public monitoring API provides summaries, distributions, certificate and PTR attention, Web Check results and recent inventory for your own integrations.

Where can I find installation instructions?

Follow the installation guide for Docker Compose or Kubernetes. The repository README introduces the project and its requirements.
